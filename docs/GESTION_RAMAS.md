# Justificación de gestión de ramas para nuestro proyecto

## 1. Justificación

Para este proyecto creemos que la mejor opción es Github Flow porque creemos en que es lo mejor para que haya comunicación en el grupo ya que es nuestro primer juego en C++ y nos dará más seguridad al gestionar las ramas.

## 2. Como hemos trabajado

Al principio, hicimos una mezcla porque comenzamos con Git Flow pero mezclando con la pull request de GitHub Flow. Al final, al afianzar la gestión de ramas, decidimos optar por GitHub Flow. Creamos ramas para features y fix y volcamos con pull request a main.
